# Survival: The Forest

This project is a simple multiplayer survival game prototype built with Godot 4.

## Features
- Player movement
- Basic combat
- Enemy collision
- Health system
- Extensible project structure for future upgrades

## How to run
1. Download and install Godot 4.
2. Open this folder in the Godot editor.
3. Press F5 to run the project.

## Goal
This is the base version of the game. We will expand it step by step.
